# ServerMenu (SurvivaIndustry)

Кастомное новогоднее главное меню Minecraft с кнопкой подключения к серверу **SurvivaIndustry**.

- **Minecraft**: 1.21.1
- **Загрузчик**: NeoForge 21.1.250
- **Язык**: Java 21
- **Сборка**: Gradle + NeoGradle (`net.neoforged.gradle.userdev` 7.0.170)

## Что делает мод

Полностью заменяет стандартное главное меню: надписи, фон-ёлку, ряд кнопок и общий новогодний стиль интерфейса.

### Главное меню
- Надписи: «Запуск на SurvivaIndustry» и «Добро пожаловать!».
- Кнопки слева сверху:
  1. **Зайти на сервер** — сразу подключает к `d24.aurorix.net:25019`
  2. **Одиночная игра**
  3. **Настройки**
  4. **Выйти**
- Фон — зимняя картинка с ёлкой, домом и фиолетово-синим небом. Адаптивный cover-рендер под любое разрешение (без искажений).

### Кнопки
Все кнопки игры (через Mixin на `AbstractButton`) перекрашены в новогодний стиль:
- закруглённые углы,
- градиент голубой → фиолетовый,
- золотистая рамка,
- при наведении — розоватый градиент и мерцающие искры,
- неактивные кнопки — тёмно-серые.

### Фон в настройках
Тот же зимний фон отображается на всех экранах настроек игры.

## Структура исходного кода

```
src/main/java/com/servermenu/
├── ServerMenuMod.java              # Main-класс мода, события экранов и фона
├── gui/
│   ├── ServerMenuScreen.java       # Кастомное главное меню
│   ├── MenuButton.java             # Новогодняя кнопка
│   ├── BackgroundRenderer.java     # Адаптивный вывод фона
│   └── RoundedRect.java            # Скруглённые прямоугольники
└── mixin/
    └── ButtonMixin.java            # Стилизация всех кнопок игры
src/main/resources/
├── servermenu.mixins.json          # Конфиг Mixin
├── pack.mcmeta
└── assets/servermenu/textures/gui/title/background/menu.png  # Фон-ёлка
```

## Сборка

```bash
# Windows (с установленным Java 21)
gradle build
```

Готовый jar появится в `build/libs/servermenu-1.0.0.jar`.

## Установка

1. Установите NeoForge для Minecraft 1.21.1 (21.1.x).
2. Скопируйте `servermenu-1.0.0.jar` в папку `mods` клиента.
3. Запустите игру профилем NeoForge.
4. В главном меню кнопка **«Зайти на сервер»** подключит к серверу SurvivaIndustry (`d24.aurorix.net:25019`).

> Примечание: стартовое окно NeoForge (красное с лисой) не меняется — оно рисуется до загрузки модов, и ни один мод не может на нём рисовать.
